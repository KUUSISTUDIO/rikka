# Rikka

Siivouskohteiden kartoitus, tarjousraportti ja siivousten kuittaus siivousyrityksille.

- Esimies: kohteet, tilakuvat ja merkinnät, A4-raportti (PDF), käyttäjähallinta, reaaliaikainen tilannekuva
- Siivooja: osoitetut kohteet, kuittaukset ja kommentit

Tausta: Supabase (EU, Frankfurt). Sovelluksessa on vain julkinen publishable-avain; käyttöoikeudet valvotaan tietokannan RLS-säännöillä.
